# MovieDude

Private Filmauswahl-App: Letterboxd-Watchlist + DVD/Blu-ray-Regal (MyMovies) + Streaming-Verfügbarkeit in Deutschland.

Film- und Streamingdaten von [TMDB](https://www.themoviedb.org), Verfügbarkeit von JustWatch. This product uses the TMDB API but is not endorsed or certified by TMDB.
